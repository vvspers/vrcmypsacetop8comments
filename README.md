# MySpace Top 8 – Discord Comments Feed

This repository is the free bridge between one Discord channel and the Unity UI in the VRChat world.

GitHub checks the Discord channel, creates `comments.json`, packs the eight Discord profile photos into one small atlas image, and publishes both with GitHub Pages.

**Do not put your Discord bot token in any file.** Add it only as a GitHub Actions secret, following `BEGINNER_SETUP.md`.
